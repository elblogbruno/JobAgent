Job Agent settings

Connection

Create a token in the Job Agent dashboard under Role Discovery, then paste it here. The token is stored only in this browser. Job Agent never asks for your LinkedIn, InfoJobs or Indeed password: those sessions stay in your browser.

Behaviour

Whether importing also tailors your CV is a backend setting, read on every import. Change it in the dashboard, on the Role Discovery page.

Keyboard shortcuts are configured at chrome://extensions/shortcuts. The defaults are Ctrl+Shift+J to import and Ctrl+Shift+K to import and prepare the application.
